# Farmila Stats - файлы для скрипта

Здесь лежат только **данные** для скрипта `[ARCHI] payday.lua` (MoonLoader, Arizona RP):

| Файл | Что это |
|---|---|
| `resource/farmila/items_atlas.png` | иконки ходовых предметов (ларцы, тайники, бумаги) |
| `resource/farmila/items_p1..3.dds` | иконки остальных предметов игры, сжатые |
| `resource/farmila/items_atlas.txt` | где в картинках лежит иконка каждого предмета |
| `idallitem.txt` | справочник названий предметов по ID |
| `config/payday/crafts.json` | база рецептов крафтов (вкладка Крафты) |
| `manifest.txt` | список файлов с размерами - по нему скрипт проверяет загрузку |

Руками ничего качать не нужно: достаточно положить `[ARCHI] payday.lua` в папку `moonloader`.
При первом запуске скрипт сам скачает эти файлы в `moonloader`, проверит размеры и включит иконки.

Кода здесь нет - только картинки и текст. Иконки предметов принадлежат Arizona RP.
